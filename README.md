## 2. 制作サイトの説明

お風呂を真っ暗な状態で入浴することを啓蒙するスピ系サイトです。

## 3. 工夫した点・こだわった点

* タイトルやテキストは本質部分ではないため、基本的にChatGPTが出力したものを使用。
* 少しだけ「やばめ」の雰囲気を出す演出もChatGPTに依頼。
* 下関の占い館デザインを参考にしようとしたが、旧態依然とした技術だったため最終的には採用を見送り。
* CSSではホバー、スライド、メニューアニメーション、Gridレイアウト、レスポンシブ対応を試行。
* JavaScriptでスクロール時に要素がふわっと出現する演出を実装。
* 各セクションを100vhで1画面単位表示し、スクロール下端でブレーキがかかるよう調整。
* フォントサイズを`rem`管理し、メディアクエリでレスポンシブに対応。
* 仕様書付きチーズアカデミーのフォーム実装で6時間格闘し、フォーム作成理解が深まる。
* 今後はAI生成コードのプロンプトエンジニアリング技術を磨きつつ活用予定。

```html
<div class="form-container">
  <form action="">
    <div class="row">
      <label for="name" class="col-25">お名前</label>
      <input type="text" id="name" name="name" class="col-75" required>
    </div>
  </form>
</div>
```

* フォーム全体のHTMLをChatGPTに生成させ、自分で微修正後にCSSも生成・修正。
* フォトショップやPremiere Proの知見を活用し、総合的な個人技術でのサイト制作を意識。

## 4. 難しかった点・次回トライしたこと（または機能）

* `block`・`inline-block`の概念理解が不十分。今後学習予定。
* 背景動画を埋め込み、下から上に流れるような演出（CSS or JS）を実現できず。
* UXへのこだわりは発見だったが、JS知識不足で「トップに戻る」機能も未実装。
* 他サイトからのJSコードをコピペして動作せず、自力修正も困難。今後JS学習に注力。
* スピ系サイトらしさが突き抜けきれず悔しいが、今回は学習優先でほどほどに。
* 次回はCSS／JS両面で動的演出を徹底的に追求したい。
